API Documentation

Base URL /

Semua endpoint mengembalikan JSON, kecuali format=text. CORS permisif penuh (semua origin, method, dan header), jadi aman dipanggil dari web/app mana pun. Butuh menembak API lain yang diblokir CORS? Pakai /api/cors. Rate limit 120 request/menit per IP.

⚡ Mulai Cepat

Salin base URL di atas, tempel ke kode kamu, lalu panggil endpoint mana pun. Contoh: ambil 10 proxy HTTP aktif dalam satu perintah.

cURL — 10 proxy HTTP 
curl "http://localhost:3000/api/proxies?type=http&limit=10"

Ganti query sesuai kebutuhan: ?type=socks5&format=text untuk daftar ip:port siap pakai, atau ?type=https&limit=20. Lihat parameter dan contoh lengkap di bawah.

Bantu Request Lintas-Origin /api/cors

Endpoint bantu untuk request yang diblokir CORS: browser menembak endpoint ini, server yang mengambil URL tujuan (bebas dari aturan CORS browser), lalu hasilnya dikirim balik dengan header CORS permisif. Default mengembalikan isi respons apa adanya (passthrough); tambahkan format=json untuk bungkus JSON.

ParameterNilaiDefaultKeterangan
urlhttps://…–Wajib. URL tujuan (http/https)
methodGET | POST | PUT | …ikut requestMethod ke URL tujuan
headers{"X-Key":"…"}diteruskanHeader request (JSON objek); content-type/accept ikut otomatis
bodyteksbody requestBody (alternatif kalau tidak kirim body langsung via POST)
formatjsonpassthroughBungkus hasil jadi JSON {status, contentType, data}

Cara pakai — 3 langkah

  1. Siapkan URL lengkap API yang mau dipanggil, contoh https://api.contoh.com/data.json.
  2. Bungkus jadi /api/cors?url= + URL tadi. Wajib di-encodeURIComponent() kalau dipanggil dari browser (biar &/? di URL tujuan tidak bentrok).
  3. Panggil seperti API biasa. Hasilnya sudah membawa header CORS permisif, jadi bisa dibaca dari origin mana pun.
cURL — GET data dari API lain 
curl "http://localhost:3000/api/cors?url=https://api.contoh.com/data.json"
cURL — POST + header kustom 
curl "http://localhost:3000/api/cors?url=https://api.contoh.com/v1/item" \
  -X POST -H 'content-type: application/json' \
  -d '{"nama":"budi"}'
JavaScript — dari browser, aman dari blokir CORS 
// server yang mengambil URL tujuan, jadi bebas blokir CORS
const apiTujuan = 'https://api.contoh.com/data.json';
const res = await fetch('/api/cors?url=' + encodeURIComponent(apiTujuan));
const data = await res.json();
console.log(data);
Python (requests) 
import requests

r = requests.get('http://localhost:3000/api/cors',
                 params={'url': 'https://api.contoh.com/data.json'})
print(r.json())
PHP (cURL) 
$url = 'https://api.contoh.com/data.json';
$ch = curl_init('http://localhost:3000/api/cors?url=' . urlencode($url));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
echo curl_exec($ch);

💡 Butuh status/content-type tujuan ikut terbaca? Semua header sudah di-expose: X-Upstream-Status, X-Upstream-Url, dan X-Elapsed-Ms. Ingin hasil dibungkus JSON? Tambahkan &format=json.

🛡️ Jadikan Browser Pakai DNS Kita /dns-query

Server ini juga bisa dipakai sebagai DNS buat browser lewat DNS-over-HTTPS (DoH). Query DNS dikirim terenkripsi di dalam HTTPS, jadi tidak bisa dibajak atau diblokir oleh DNS operator/ISP — website yang tumbang gara-gara “DNS nakal / Internet Positif” bisa diakses lagi. Tambahkan proxy dari daftar di atas supaya IP-mu juga ikut berganti.

DoH URL /dns-query

⚠️ Browser hanya menerima DoH yang HTTPS. Untuk dipakai perangkat lain, deploy dulu ke hosting ber-HTTPS (Railway/VPS + domain), lalu pakai https://domain-kamu/dns-query. Saat dites di komputer sendiri, http://localhost:3000/dns-query juga jalan.

Cara setel di browser & perangkat

Browser / OSMenuIsi dengan
Chrome, Edge, Brave, Opera Settings → Privacy and security → Security → Use secure DNS → Custom URL DoH di atas
Firefox Settings → Privacy & Security → DNS over HTTPS → Max Protection → Custom URL DoH di atas
Android 9+ Setelan → Jaringan → DNS Pribadi (Private DNS) → Nama host penyedia domain-kamu.com tanpa https:// dan tanpa /dns-query
Windows 11 Settings → Network → Wi-Fi/Ethernet → DNS server assignment → Manual → DoH on URL DoH di atas
Desktop app / lain-lain Set “DoH / DNS over HTTPS” ke URL di bawah URL DoH di atas

Tipe record yang didukung

A, AAAA, CNAME, MX, TXT, NS, SOA, SRV, PTR, CAA, dan ANY. Tipe lain dijawab NOTIMP (belum didukung).

Tes cepat

cURL — tanya DNS dalam JSON 
curl "http://localhost:3000/dns-query?name=example.com&type=A"

# hasil:
{
  "Status": 0,
  "Question": [{ "name": "example.com.", "type": 1 }],
  "Answer": [{ "name": "example.com.", "type": 1, "TTL": 300, "data": "93.184.216.34" }]
}
JavaScript — resolve domain dari browser 
// CORS sudah permisif, jadi bisa dipanggil langsung dari halaman web
const res = await fetch('/dns-query?name=example.com&type=A');
const { Status, Answer } = await res.json();
console.log(Status, Answer.map((a) => a.data));
Mode DNS server (opsional) — setelan perangkat/router 
# jalankan server dengan DNS_SERVER=true (butuh port 53)
DNS_SERVER=true DNS_PORT=53 npm start

# lalu arahkan DNS perangkat/router ke IP server ini, dan tes:
dig @192.168.1.10 example.com A
nslookup example.com 192.168.1.10

💡 Endpoint ini juga melayani wireformat RFC 8484 (GET /dns-query?dns=<base64url> dan POST /dns-query dengan Content-Type: application/dns-message) — itu yang dipakai browser saat kamu memasang URL DoH di atas. Upstream resolver bisa diganti lewat DNS_UPSTREAM=1.1.1.1,8.8.8.8.
