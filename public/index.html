API Documentation

Base URL / — semua endpoint mengembalikan JSON, kecuali format=text. CORS aktif, jadi aman dipanggil dari web/app lain. Rate limit 120 request/menit per IP.

Contoh

cURL — ambil 50 proxy HTTP 
curl "http://localhost:3000/api/proxies?type=http&limit=50"
Daftar teks siap pakai (SOCKS5, tanpa skema) 
curl "http://localhost:3000/api/proxies?type=socks5&format=text"

JavaScript (fetch) 
const res = await fetch('http://localhost:3000/api/proxies?type=https&limit=20');
const { data, meta } = await res.json();
console.log(meta.total, data);
Python (requests) 
import requests

r = requests.get('http://localhost:3000/api/proxies', params={'type': 'http', 'limit': 20})
for p in r.json()['data']:
    print(p['proxy'], p['anonymity'], p['latencyMs'])
